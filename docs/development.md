# Development

## Setup

```bash
uv sync --extra all   # install every optional DB driver too, for full test coverage
```

## Checks

```bash
uv run ruff check .          # lint
uv run ruff format .         # format
uv run ty check              # type check
uv run pytest                # unit + integration tests, with coverage
```

`tests/unit/` covers individual modules in isolation (config parsing, the cache backend, the
comparator logic, the Excel exporter, the CLI via `typer.testing.CliRunner`).
`tests/integration/` runs real SQLite-to-SQLite validations through `ValidationRunner` and the
REST/web app through FastAPI's `TestClient` — see `tests/conftest.py` for the shared fixture
data (a source/target SQLite pair with a few intentional mismatches, used across most tests).

## Project layout

```
src/pydoublecross/
├── config/        # YAML schema (pydantic models) + loader/saver
├── datasources/    # one SQLAlchemy-backed connector + a type->driver registry
├── cache/          # Parquet file cache + the enable/override decision logic
├── validation/      # per-side GE checks, cross-source pandas diff, orchestration
├── reporting/       # result -> tabular rows -> Excel (Exporter ABC for more formats)
├── core/runner.py  # ValidationRunner - the one orchestration entry point
├── cli/             # Typer app
├── api/             # FastAPI REST routers
└── web/              # Jinja2 templates + page routes, mounted alongside the API
```

CLI, REST API, and web UI are all thin front ends over `core.runner.ValidationRunner` — new
behavior belongs there or in the module it orchestrates, not duplicated per front end.

## Versioning

CalVer: `YYYY.MM.MICRO` (e.g. `2026.7.1`), tracked in `src/pydoublecross/__init__.py` and read by
Hatch via `[tool.hatch.version] path = "src/pydoublecross/__init__.py"`. Bump `MICRO` within a
month; start a new `MICRO` sequence at `1` when the month changes.

## Building the docs

```bash
uv run mkdocs serve   # live-reloading local preview
uv run mkdocs build   # static site in site/
```
